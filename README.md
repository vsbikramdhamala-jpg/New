# EduConsult OMS — 10 Page Frontend

BCA Final Project frontend for an Educational Consultancy Office Management System.

## Pages
1. Dashboard
2. Student Management
3. Application Tracking
4. Document Center
5. Universities & Courses
6. Counseling & CRM
7. Appointments & Follow-ups
8. Staff & Sub-Agent Management
9. Finance & Payments
10. Reports & Settings

Plus:
- Login page
- Responsive navigation
- Role display
- Dark mode
- Search UI
- Tables
- Forms
- Kanban application pipeline
- Dashboard analytics
